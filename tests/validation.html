RT60 validation

Synthetic rooms of known reverberation time run through the application's own analysis (AM.analysis) and decision (AM.services.processing). Development only; the application never loads this page.

Expected = the room's own decay in that band, taken from its noise-free impulse response (no sweep, no noise, no measuring device) over the same ISO 3382-2 range as the measurement (T30 −5…−35 dB, T20 −5…−25 dB). A synthetic octave band decays within a few per cent of its nominal RT (most spread at 125 Hz), so errors are against Expected; the nominal value and the error against it are shown too. Tolerance: 5 % for T30, 8 % for T20. "Before" re-runs the same recording with the analysis as it was before this audit (no direct-sound cap, no gap check, the 60 dB fit first from 75 dB usable decay).
