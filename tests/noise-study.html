Background noise: what the check says against what the take shows

Six backgrounds built on one stationary room noise (about −49.5 dBFS broadband, mostly ventilation rumble). For each: the background-noise check, and RT60 takes made in that background, scored against the room's own decay. Development only; the application never loads this page. Add ?sweep=3 to run the takes with a 3 s sweep.
